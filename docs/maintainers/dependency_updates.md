# OfficeWeave 依存の更新

本書は maintainer 向けである。寄稿者が読む必要は無い。

何を確かめるかは [技術構成](../development/tech_stack.md) と
[設計原則](../development/architecture.md#10-依存を足すときに確かめること) が持つ。
本書が持つのは、いつ、どの単位で作業するかである。

## パッチ更新

- セキュリティ修正を含むパッチ更新は、確認でき次第、単独のタスクとして適用する
- 適用時は、全検証が成功することを確認してからマージする

## マイナー更新

- 同一メジャー系列内の更新は、四半期に一度を目安に確認する
- 更新は単独のタスクとして扱い、機能追加と同じ変更に含めない

## メジャー更新

- メジャー更新は、独立したタスクとして計画する
- 変更点、非互換、移行手順を残す
