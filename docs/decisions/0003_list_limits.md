# 0003 時間で並ぶ一覧に、期間とページ送りの両方を持たせる

- 日付: 2026-08-06
- 状態: 採用

本記録は、この日付の時点での実測に基づく判断である。以後の値は追わない。
版ごとの実測は [版ごとの検証](../releases/) が持つ。

## 状況

予定の一覧は、開始日以降のすべてを上限なく並べていた。1 年先まで予定を
積んだ組織では、その全部が 1 回の要求で返る。

想定規模（利用者 400 人、主要な記録が各 1 万件）で測った結果である。

```text
上限を入れる前の予定の一覧   266 KB
上限を入れたあと             16 KB
```

## 判断

時間の並びで見る一覧には、ページ送りではなく期間を持たせる。予定や予約は
「次の何件」ではなく「いつからいつまで」で見るためであり、番号で区切ると
同じ日の記録が 2 ページに分かれる。

期間だけでは足りない。終わりを遠くへ指定すれば同じことが起きる。期間の
長さにも上限を置き、その内側でもページ送りを持たせる。

規則は `DateWindow` が持つ。既定の日数と上限の日数は、そこが正本である。

## 結果

いずれの一覧も、記録の数に比例して読み込む量が増えることは無くなった。
比例していないことは、想定規模での測定で版ごとに確かめる。
