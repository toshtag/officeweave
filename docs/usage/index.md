# OfficeWeave 操作の手引き

本書は、画面から行う操作の手順を持つ。役割ごとに読む場所を分ける。

環境の導入、設定、監視、バックアップは [運用管理](../operations/administration.md) と
[設定](../operations/configuration.md) が持つ。ここでは画面の操作だけを扱う。

## 役割

```text
利用者    自分の仕事のために画面を使う人
管理者    組織の情報と利用者を預かる人。利用者ができることはすべてできる
```

管理者だけが使える操作には「管理者」と書く。書いていない操作は誰でも行える。

## 画面の使い方に共通すること

### 見えないものは、権限か公開範囲で決まる

一覧に出ないものには 2 つの理由がある。

```text
権限      その操作を行える役割ではない
公開範囲  その記録が自分へ公開されていない
```

どちらの場合も、画面には理由を書かない。書くと、見えないはずの記録の存在が
分かってしまう。心当たりのないときは、記録を作った人か管理者に尋ねる。

### 失敗したときは、画面の上に出る

保存できなかった場合、入力欄の上に理由が並ぶ。理由は入力した項目ごとに出る。

権限が足りない操作は「この操作は実行できません」と出る。やり直しても結果は
変わらない。

「操作の途中で状態が変わりました」と出た場合は、別の人が同じ記録を変えている。
画面を開き直すと、いまの状態から続けられる。

### 狭い画面と拡大

画面の幅が 320 px でも、すべての機能へ届く。表は、その箱の中で横へ動かせる。
キーボードだけを使う場合は、Tab で表の箱へ焦点を移し、矢印で動かす。

### 表示する言語

画面右上で切り替える。切り替えた言語は次に開いたときも続く。
既定は利用者ごとの設定であり、[自分の設定](getting_started.md#自分の設定) で決める。
