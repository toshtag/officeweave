# お知らせと文書

組織の中で読み書きする情報を扱う。

## お知らせ

### 読む

`/announcements` に、自分へ公開されたものが新しい順に並ぶ。未読には印が付く。

題名と本文で検索できる。部分一致であり、語の区切りは要らない。

開いた時点で既読になる。読んだかどうかを自分で申告する形にはしていない。

### 書く（管理者）

`/announcements/new` で作る。公開範囲は 2 つから選ぶ。

```text
組織全体      その組織の利用者すべて
指定した部門  選んだ部門に属する利用者だけ
```

部門を選ぶ欄には上限がある。多い組織では、絞り込んでから選ぶ。既に選んで
ある部門は、絞り込んでも外れない。

公開日時を先の時刻にすると、その時刻まで公開されない。公開待ちは一覧の
別の区分に出る。作った本人が確認も訂正も取り消しもできる。

公開日時を入れずに保存すると下書きになる。下書きは作った本人だけが見られる。

公開すると、対象の利用者へ通知が届く。外部の宛先を登録している場合は、
そちらへも送られる。

## 文書

### 読む

`/documents` に、自分へ公開されたものが並ぶ。分類で絞り込める。

題名、本文、添付ファイルの名前で検索できる。

添付ファイルは、その文書を読める利用者だけが取得できる。経路を知っていても、
公開範囲の外からは開けない。

### 書く

`/documents/new` で作る。公開範囲の決め方はお知らせと同じである。

添付できるファイルの数と大きさには上限がある。超えた場合は、保存する前に
理由が出る。

### 分類（管理者）

`/document_categories` で作り、並び順を決める。

分類は文書の並べ方であり、読める範囲は決めない。読める範囲は文書ごとの
公開範囲が持つ。分類を絞り込んでも、読めない文書は出てこない。

分類に属する文書がある間は、その分類を消せない。
