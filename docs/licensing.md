# OfficeWeave ライセンスと名称の利用方針

本書は、ソースコードのライセンスと、製品名の取り扱いを定義する。

## 1. ソースコードのライセンス

```text
GNU Affero General Public License version 3 or later (AGPL-3.0-or-later)
```

全文は [LICENSE](../LICENSE) に置く。

```text
Copyright (C) 2026 OfficeWeave contributors
```

### 選定理由

- 最初の提供形態はセルフホストであり、利用者が改変して運用できる状態を保ちたい
- 将来この製品を運用込みで提供する可能性があり、その選択肢を残したい
- AGPL-3.0 はネットワーク越しの提供にも改変部分の公開を求めるため、
  原作者以外が改変版を非公開のサービスとして提供する状況を防げる
- 組織内部での利用、設定、改変には追加の義務が生じない

### 検討した代替案

| 候補           | 採用しなかった理由                                    |
| ------------ | -------------------------------------------- |
| MIT          | 改変版を非公開のサービスとして提供でき、セルフホスト利用者へ改変内容が還元されない    |
| Apache-2.0   | 特許条項は有用だが、ネットワーク提供時の公開義務がなく、上と同じ課題が残る        |
| GPL-3.0      | 配布を伴わないネットワーク提供に公開義務が及ばず、本製品の利用形態と合わない      |
| 独自ライセンス      | 利用者側の法務確認の負担が大きく、導入判断を遅らせる                    |

### 利用者への影響

- 自組織で導入し、業務で利用することに制限はない
- 自組織向けに改変して利用することにも制限はない
- 改変版を第三者へ提供する場合、またはネットワーク越しのサービスとして
  第三者へ提供する場合は、対応するソースコードを提供する必要がある

## 2. 依存ライブラリのライセンス

依存を追加する際は、PR 本文へライセンスと保守状況を記録する。

次のライセンスは、本体の配布条件と両立しないため採用しない。

- 商用利用を禁じるもの
- 利用分野や利用者を制限するもの
- 再配布を禁じるもの
- ソースコードが公開されていないもの

判断が難しい場合は、その依存を採用せず、代替手段を検討する。

## 3. 製品名と識別子の利用方針

```text
製品表示名: OfficeWeave
技術識別子: officeweave
```

名称そのものは、ソースコードのライセンスとは別に扱う。

### 許可すること

- 本製品を導入・運用していることの表明
- 本製品に関する解説、記事、講演、比較評価
- 改変せずに配布する場合の名称の使用
- 互換性や連携の説明における名称の言及

### 事前の許可を求めること

- 改変版へ、同一または誤認を招く名称を付けて配布すること
- 本プロジェクトが提供・承認していると受け取れる名称の使用
- 名称を含む独自のサービス名、製品名、組織名の使用

改変版を配布する場合は、AGPL-3.0 の条件を満たしたうえで、
本プロジェクトと区別できる名称を使用する。

### 商標登録

現時点で商標登録は行っていない。
登録の有無にかかわらず、上記の方針を運用上の基準とする。

現時点では、貢献者ライセンス契約の締結は求めない。
求める必要が生じた場合は、本書を更新したうえで導入する。
