# OfficeWeave 全体ロードマップ

本書は中長期の Phase、目的、開始条件、完了条件だけを記録する。
Phase の順序と内容を変更する場合は、本書を更新したうえで行う。

現在地と実行順は本書には書かない。正本は [実行キュー](execution_queue.md) だけとする。

## 進行情報の責任分界

進行に関わる情報は、次の 4 か所で役割を分ける。同じ情報を複数箇所へ複製しない。

```text
docs/roadmap.md
  中長期の Phase、目的、開始条件、完了条件
docs/execution_queue.md
  現在地、次のタスク、実行順、タスク状態
GitHub Issue
  不具合の再現、影響、修正方針、完了条件
GitHub PR と Git 履歴
  実際の変更、検証結果、マージ証跡
```

### CI の導入時期

CI は P2 では扱わず、P12 完了後の最終工程 F でのみ導入する。

P2 の目的は、開発者が手元で品質を確認できる状態を作ることである。
検証手段が固まる前に CI を組むと、実装途中の暫定的な手順が設定として固定され、
毎 Phase で CI 設定の保守が発生する。

したがって P2 から F までは、すべての検証をローカルで実行する。
F では、その時点で確立した検証コマンドをそのまま CI へ移す。

### 開発制御ツールについて

外部の開発制御ツールは導入しない。

進行状態はロードマップと実行キュー、および Git の履歴で管理する。
1 タスク 1 ブランチ 1 PR を守れば、`git log` と PR 一覧から現在地を復元できるため、
専用ツールを実行環境へ持ち込む必要がない。

以前のロードマップにあった Agent 向け read/write scope の固定タスクも取りやめる。
変更範囲は、実行キューの各タスク定義とブランチ単位の差分で表現する。

## R0 以降の位置づけ

P0 から F までで、セルフホスト版の機能範囲と検証手段は一巡した。
ただし F 完了後の静的レビューで、データ消失と外部への到達に関わる不具合が確認された。
機能を足す前に、これらを解消する Phase を R0 として置く。

R1 以降は、現時点で不具合ではないが、実運用へ入る前に必要と判断した項目である。
不具合は GitHub Issue で管理し、機能追加は本書で管理する。両者を混ぜない。

### R0 安定化

登録済みの不具合 Issue を、重大度と依存関係の順に修正する。
新しい機能を足さない。修正の範囲は Issue の完了条件に閉じる。

Issue の実行順は [実行キュー](execution_queue.md) に記録する。

R0 の最後には、全 Issue、全検証、文書、配布構成の整合を確かめる安定化完了監査を置く。
R0 が完了するまで、GitHub Release による公開リリースは作成しない。

R0 は完了した。監査の結果は [実行キュー](execution_queue.md) に記録する。

開発制御の専用ツールは、P0 で決めたとおり今後も導入しない。
進行状態は実行キューと Git の履歴だけで管理する。

## 進行規則

- 1 タスクにつき 1 ブランチ 1 PR とし、独立して検証できる単位まで分解する
- ブランチ名は `p<Phase>/t<連番>-<短い英語>` とする
- ブランチ内のコミットは目的ごとに分ける
- 実装 → 対象テスト → Lint とセキュリティ検査 → 差分確認 → PR 作成の順に進める
- 検証がすべて成功した場合にのみ、merge commit 方式で `main` へマージする
- squash merge と rebase merge は使用しない。分割したコミットを履歴に残す
- マージ後は作業ブランチをリモートとローカルの両方から削除する
- 検証失敗、競合、未コミット変更がある状態ではマージしない
- 先行するタスクの完了条件を満たさないまま、次のタスクへ進まない
- 各 Phase は網羅性ではなく、前後の機能と接続された最小の垂直スライスとして完成させる
- 将来 Phase の機能を先行実装しない
- Phase をまたぐ変更が必要になった場合は、実装前に本書と実行キューを更新する

## P13 の開始条件

P13 は、次のいずれかが実際に発生するまで着手しない。

- 組織からホスティング提供の具体的な要望が届く
- 継続的な利用希望が複数確認される
- セルフホスト導入支援だけでは解決できない需要が確認される
- 運用費用を賄える契約の可能性がある

認知獲得だけを目的として、常設の公開環境を先行して用意しない。
